  (defun prot/keyboard-quit-dwim ()
    "Do-What-I-Mean behaviour for a general `keyboard-quit'.

  The generic `keyboard-quit' does not do the expected thing when
  the minibuffer is open.  Whereas we want it to close the
  minibuffer, even without explicitly focusing it.

  The DWIM behaviour of this command is as follows:

  - When the region is active, disable it.
  - When a minibuffer is open, but not focused, close the minibuffer.
  - When the Completions buffer is selected, close it.
  - In every other case use the regular `keyboard-quit'."
    (interactive)
    (cond
     ((region-active-p)
      (keyboard-quit))
     ((derived-mode-p 'completion-list-mode)
      (delete-completion-window))
     ((> (minibuffer-depth) 0)
      (abort-recursive-edit))
     (t
      (keyboard-quit))))

*** Switch to or create a perspective

I use this function a 1000 times a day when I enter any kind of code / documentation project with my =bin/tn= or =bin/ta= helpers.

It is called with the two last directory segments (e.g. =Code/something=), which will become the name of the perspective **and** the matching tmux session. So, whenever I need to switch contexts, I can either just peek into anther project by switching perspectives, or go all in and switch the tmux session. Both names match.

#+begin_src emacs-lisp :tangle init.el
  (defun bascht--switch-to-or-load-perspective (name &optional directory)
    (interactive)
    (require 'magit-git)
    (persp-mode)
    (if (member name (persp-names))
        (persp-switch name)
      (progn (persp-new name)
             (persp-switch name)
             (project-switch-project directory)
             (when (magit-git-repo-p directory)
               (progn
                 (magit-fetch-all nil)
                 (magit-status-setup-buffer)
                 (delete-other-windows))))))
#+end_src
